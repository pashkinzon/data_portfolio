# Pavel Polishchuk — Data Portfolio

Personal portfolio for data analysis, automation, and rapid prototyping.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm test
```

The production build is a static export in `out/`.

## Deployment

Every push to `main` runs the GitHub Pages workflow and deploys the static export to:

<https://pashkinzon.github.io/data_portfolio/>
